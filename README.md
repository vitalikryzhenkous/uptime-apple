# uptime-apple

macOS menu-bar app (later iOS and widgets) for [uptime-board](https://github.com/vitalikryzhenkous/uptime-board) —
live Claude Code sessions, plan limits and Buddy the cat, from the board's API v1
(contract: `uptime-board/docs/api.md`).

- `UptimeKit/` — Swift package shared by every target: API models, client, localization, sprites.
- `Apps/Mac/` — the menu-bar app (macOS 14+; Liquid Glass on macOS 26, `.ultraThinMaterial` before).
- `project.yml` — the Xcode project, generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen).

## Build (on the Mac)

```sh
brew install xcodegen
cp Config/Local.xcconfig.example Config/Local.xcconfig   # put your Team ID there (not committed)
xcodegen generate
open Uptime.xcodeproj
```

Package tests without Xcode UI: `swift test --package-path UptimeKit`.

The token (`UPTIME_API_TOKEN` from the board's `.env`) is entered in the app's settings and kept in the Keychain —
never in this repo.
